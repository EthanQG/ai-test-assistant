# 登录模块常见Bug
1. 用户名包含特殊字符导致SQL注入
2. 密码明文传输
3. 多次登录失败未锁定账户
4. 验证码过期未刷新
5. 登录状态未正确维护

# 支付模块常见Bug
1. 重复支付导致金额翻倍
2. 支付超时未回滚订单状态
3. 优惠券使用后退款未返还
4. 金额计算精度丢失
5. 支付回调签名验证缺失

# 订单模块常见Bug
1. 库存超卖
2. 订单状态流转错误
3. 删除订单后数据残留
4. 订单并发创建导致数据不一致
5. 订单查询性能问题

# 用户模块常见Bug
1. 用户信息修改未校验权限
2. 用户删除未级联清理相关数据
3. 用户密码重置逻辑缺陷
4. 用户注册重复提交
5. 用户头像上传安全问题

# 通用Bug模式
1. 空值判断缺失导致NullPointerException
2. 数组越界访问
3. 资源未正确释放（数据库连接、文件句柄）
4. 并发竞争条件
5. 异常处理不完整
6. 日志记录不充分
7. 输入参数未校验
8. 时间格式处理错误
